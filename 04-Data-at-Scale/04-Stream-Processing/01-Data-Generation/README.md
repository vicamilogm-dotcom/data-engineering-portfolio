# 🎯 Goal

The goal of this exercise is to take you through the process of how the synthetic data you will use in the next challenge was created.

The synthetic data is a time series coming from 4 different sensors.
- `AtmP`
- `Temp`
- `Airtight`
- `H20C`

We will use jupyter notebook to walk through the synthetic data creation and visualise it to gain a deeper understanding of what we are working with.

<br>

# 1️⃣ Open in Jupyter

To execute jupyter notebook in your VM, you have two options.

## 1.1. Use the jupyter interface in VS Code

Open `notebook/visualize.ipynb`, make sure you are connected to the correct kernel, and follow the instructions.

## 1.2. Use the jupyter interface in your browser

Run this command:

```bash
jupyter notebook --NotebookApp.token='' --NotebookApp.password='' --port 8888
```

Make sure that port 8888 has been forwarded and open localhost:8888 in your browser.

<br>
