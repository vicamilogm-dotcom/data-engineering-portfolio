🎯 This exercise takes you through visualising the data that we are going to publish.

We will use jupyter notebook for this challenge.

To execute jupyter notebook in your VM, you have two options.

## 1. Use the jupyter interface in VS Code

Open `notebook/visualize.ipynb` and follow the instructions.

## 2. Use the jupyter interface in your browser

Run this command:

```bash
jupyter notebook --NotebookApp.token='' --NotebookApp.password='' --port 8888
```

Make sure that port 8888 has been forwarded and open the relevant localhost in your browser.<br>

Now  open `notebook/visualize.ipynb` and follow the instructions.
