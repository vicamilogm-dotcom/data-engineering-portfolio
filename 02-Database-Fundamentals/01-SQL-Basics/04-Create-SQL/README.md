# 🎯 Goal

This is an advanced optional exercise. It is not required for a data engineer to have such in depth knowledge, but it is interesting and can help in some scenarios!

❓ Your job is to create the ability to insert data and select data, being able to restrict it to only some columns.

The ability to create tables is already implemented in `lwsql`

The part to deal with the disk operations is already created in `btree.py`.

Ues pytest to help you.

You will need to check out the [pyparsing documentation](https://pyparsing-docs.readthedocs.io/en/latest/index.html) in order to understand how to process SQL statements.

Good luck! 🚀
