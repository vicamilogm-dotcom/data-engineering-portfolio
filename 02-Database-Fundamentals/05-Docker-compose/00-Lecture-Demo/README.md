# Notes

- For lectures - please use this package as a reference, build the package throughout the lecture.
- There is no `.envrc` with `layout_poetry` in this package, ensure you prepend `poetry run` to commands.
- Be careful with the paths for running the FastAPI app.
- Able to be run in a local Unix-like environment (MacOS/Linux/WSL). Recommended to do lecture on a VM to reinforce port forwarding.
