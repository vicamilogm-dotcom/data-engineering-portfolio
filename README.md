# Data Engineering Portfolio

Ejercicios y proyectos del **bootcamp de Data Engineering de Le Wagon (2026)**, resueltos por [Victor Grajales](https://www.linkedin.com/in/victorcamilograjales).

> Los enunciados y la estructura base son material del curso de Le Wagon; las soluciones son propias.

## Qué cubre

| Módulo | Temas | Tecnologías |
|---|---|---|
| [01 · Software Engineering Best Practices](01-Software-Engineering-Best-Practices) | Linux y Bash, Python para datos, buenas prácticas, data lakes, despliegue | Python, Poetry, pytest, Docker |
| [02 · Database Fundamentals](02-Database-Fundamentals) | SQL, data warehousing, SQL avanzado, backend y gestión de bases de datos | PostgreSQL, SQL, Docker Compose |
| [03 · Data Storage & Batch Pipelines](03-Data-Storage-and-Batch-Pipelines) | ETL, ELT, orquestación de pipelines, visualización | Airflow, dbt, Kubernetes |
| [04 · Data at Scale](04-Data-at-Scale) | Procesamiento distribuido, Spark avanzado, streaming | Spark, Pub/Sub streaming, escalamiento de APIs |
| [05 · Projects](05-Projects) | Trabajo en equipo, infraestructura como código, bases de grafos y NoSQL | Terraform, Neo4j, MongoDB |

## Cómo está organizado

Cada módulo tiene su propio `README.md` y carpetas por día con los ejercicios. El `Makefile` y `make.inc` contienen las tareas comunes de pruebas y estilo.

## Contexto

Este repositorio complementa mi experiencia en producción: pipelines de datos sobre SQL Server, Databricks / Delta Lake, modelos LSTM de pronóstico de demanda y agentes de IA sobre ERP.
